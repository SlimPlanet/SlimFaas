# Contributing

To get started with the repository:

```sh
git clone https://github.com/SlimPlanet/SlimFaas.git

```
You are now ready to contribute!

## Build quality

Warnings are errors and every .NET analyzer is enabled for the whole repository (`Directory.Build.props`, `.editorconfig`, `eng/*.globalconfig`). New code must build clean; suppressions are scoped and justified. See the "Build quality" section of [AGENTS.md](./AGENTS.md) for the rules.
