# Web UI: BEM is required

- BEM is mandatory for new or modified styles: `block`, `block__element`, `block--modifier`, `block__element--modifier`; keep the base class when applying a modifier.
- Use component-owned classes with explicit state modifiers; update JSX, generated HTML, SCSS and JavaScript selectors together; organise SCSS per component; no inline styles, no styling by ID or unrelated ancestor structure.
- Exceptions, kept narrow: global resets and tokens, typography scoped to a Markdown content block, classes generated by third-party renderers (Mermaid, Highlight.js). Do not rename library-owned classes.
- Preserve the branding: the primary blue is `#0000ff`; reuse the application's central colour token.
- Verify responsive layout, keyboard navigation and dynamic content after class changes; migrate existing screens as they are touched, no wholesale rewrite.
- Checks: dashboard `(cd src/SlimFaas/ClientApp && npm ci --ignore-scripts && npm test && npm run build && npm run build-storybook)`; Planet Saver `(cd src/SlimFaasPlanetSaver && pnpm i --frozen-lockfile && pnpm run coverage)`; site `(cd src/SlimFaasSite && pnpm install --frozen-lockfile && pnpm build)`.
